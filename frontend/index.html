End-to-End Product Flow

User Uploads Road Image
↓ POST /analyze-image
Modular Detection Service (YOLO / PyTorch / OpenCV)
↓ Bounding Boxes & Confidence
AI Severity Engine & Priority Estimator
↓ GPS Location & Review
SQLite Database Report Storage
↓ Synchronized Persistence
Interactive Leaflet GIS Map & Analytics Dashboard

Technology Stack & Standards

  • Backend API: Python 3.10+, FastAPI, Uvicorn
  • Computer Vision: Pillow (PIL), Ultralytics YOLO / OpenCV DNN
  • Database: SQLite, SQLAlchemy ORM
  • GIS Mapping: Leaflet.js, OpenStreetMap
  • Analytics: Chart.js
  • Frontend UI: HTML5, Vanilla CSS3, JavaScript (ES6)
